# Web Gauntlet Infrastructure

P10 assigns unique loopback review ports 4201–4210, validates every project and
archetype route, creates isolated evidence/build directories, and executes a live
HTTP service lifecycle probe. Each P11 application gate runs its existing domain
tests, materializes the deterministic React/Vite experience, performs an offline
locked install, builds, runs the web and mutation oracles, writes a machine
certificate, starts its review service, and performs a health check.
